Configuração NixOS

Sistema Linux declarativo e reprodutível, em dual boot com o Windows, montado de raiz no meu portátil.

O que é

O NixOS é uma distribuição Linux em que todo o sistema é descrito em ficheiros de configuração escritos na linguagem Nix. Em vez de instalar e configurar programas à mão, escrevo o que quero e o sistema é construído a partir daí. A minha configuração usa Flakes (nixpkgs 26.05) e Home Manager, e está dividida em módulos.

Para que serve

É o sistema que uso no dia a dia para estudar e programar. Como tudo está em ficheiros, posso voltar a uma versão anterior no menu de arranque se algo correr mal, e reinstalar o mesmo sistema noutra máquina com os mesmos ficheiros. O Windows continua instalado no mesmo disco.

KDE Plasma

  • Ambiente de trabalho completo e tradicional.
  • Foi o primeiro ambiente instalado.
  • Fica disponível como alternativa no ecrã de início de sessão.

Hyprland

  • Gestor de janelas em mosaico (tiling), configurado em Lua.
  • Barra e painéis com o Caelestia shell.
  • Walker como lançador de aplicações.
  • Terminal com a shell fish.

Estrutura da configuração

Cada parte do sistema tem o seu ficheiro, o que torna a configuração mais fácil de ler e de alterar: 

/etc/nixos
├── flake.nix            # entradas: nixpkgs, home-manager
├── configuration.nix    # configuração principal
└── modules/
    ├── default.nix      # junta todos os módulos
    ├── packages.nix     # programas instalados
    ├── Nvidia.nix       # placa gráfica
    └── calestia.nix     # Caelestia shell

Capturas de ecrã

Alguns aspetos do sistema a funcionar no portátil.

Pormenores técnicos

  • Placa Nvidia: o portátil tem gráfica integrada e Nvidia, e a BIOS não permite escolher entre elas. Configurei o PRIME offload, para usar a Nvidia só quando é preciso.
  • Suspensão: o portátil só suporta o modo s2idle e o ecrã ficava preto ao acordar. A solução foi usar hibernação, com uma swap de 18 GiB criada para isso.
  • Dual boot: o menu de arranque mostra as versões do NixOS e o Windows. Tive de acertar o relógio entre os dois sistemas e desligar o arranque rápido do Windows.
  • Flakes: comecei sem Flakes e converti a configuração depois, para fixar as versões dos pacotes.
